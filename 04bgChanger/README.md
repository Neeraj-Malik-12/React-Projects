# Background Color Changer

A simple and interactive background color changer built using React and Tailwind CSS.  
This project allows users to change the background color of the screen dynamically by clicking different color buttons.

---

## Preview

The application displays multiple color buttons at the bottom of the screen.  
Clicking any button instantly changes the background color of the page.

---

## Features

- Dynamic background color changing
- Built with React functional components
- Uses React `useState` Hook
- Reusable Button component
- Responsive button layout
- Smooth UI styling with Tailwind CSS
- Conditional text color handling for better visibility

---

## Tech Stack

- React
- Tailwind CSS
- Vite
